# NAO VR Companion App

Flutter companion/social app prototype for the NAO VR game project.

## Features

- Player profile screens
- Feed, posts, comments, and chat UI prototypes
- Shared visual constants for NAO VR styling

## Setup

```bash
flutter pub get
flutter analyze
flutter run
```

This app is part of the root NAO VR repository. See the root `README.md` for the Unity, firmware, and tracking-tool setup.
